# siap

Opinionated Taskwarrior TUI. Tabbed task list with a task inspector, backed by the `task` CLI.

## Prerequisites

- macOS on Apple Silicon (arm64)
- [Taskwarrior](https://taskwarrior.org/) — installed automatically as a Homebrew dependency

## Install with Homebrew

```sh
brew install iman1704/tap/siap
```

This taps `iman1704/homebrew-tap` and installs the `siap` binary.

## Run

```sh
siap
```

## Upgrade

```sh
brew upgrade iman1704/tap/siap
```

## Uninstall

```sh
brew uninstall siap
```
